# 12. Glossary

| Term            | Meaning                                                                              |
| --------------- | ------------------------------------------------------------------------------------ |
| Gate            | An automated check that code must pass before it gets into the project               |
| Scenario        | A Gherkin description of one behavior (`Given` / `When` / `Then`), the specification |
| Step definition | The code that connects a scenario sentence to the application                        |
| Mutant          | A deliberately broken copy of the code; a test must fail on it                       |
| CRAP score      | complexity² × (1 − coverage)³ + complexity, per function                             |
| ADR             | Architecture Decision Record: one decision, its reasons and how it is checked        |
| Trailer         | A `Key: value` line at the end of a commit message, such as `Assisted-by`            |
| Release PR      | The pull request release-please keeps open with the next version and the CHANGELOG   |
