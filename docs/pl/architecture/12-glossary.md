# 12. Słownik

| Pojęcie         | Znaczenie                                                                                  |
| --------------- | ------------------------------------------------------------------------------------------ |
| Bramka (gate)   | Automatyczne sprawdzenie, które kod musi przejść, zanim trafi do projektu                  |
| Scenariusz      | Opis jednego zachowania w formacie Gherkin (`Given` / `When` / `Then`), czyli specyfikacja |
| Step definition | Kod, który łączy zdanie ze scenariusza z aplikacją                                         |
| Mutant          | Celowo zepsuta kopia kodu; test musi na niej nie przejść                                   |
| Wynik CRAP      | złożoność² × (1 − pokrycie)³ + złożoność, dla każdej funkcji                               |
| ADR             | Architecture Decision Record: jedna decyzja, jej powody i sposób sprawdzania               |
| Trailer         | Wiersz `Klucz: wartość` na końcu wiadomości commita, np. `Assisted-by`                     |
| Release PR      | Pull request, który release-please utrzymuje otwarty z następną wersją i CHANGELOG         |
